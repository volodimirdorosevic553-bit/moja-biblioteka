# Moja Biblioteka — projekt semestralny, dzień 2

Autor: Volodymyr Doroshevych  
Indeks: 77442

To jest drugi etap projektu. Aplikacja nie korzysta już z localStorage, tylko z bazy danych Supabase.

## Co działa w tej wersji

- dodawanie książki do bazy Supabase,
- pobieranie listy książek z bazy,
- wyświetlanie szczegółów książki,
- usuwanie książki z bazy,
- wyszukiwanie po tytule lub autorze,
- filtrowanie po gatunku,
- licznik książek.

## Technologie

- HTML — struktura strony,
- CSS — wygląd aplikacji,
- JavaScript — logika aplikacji,
- Supabase — baza danych PostgreSQL i API.

## Tabela w Supabase

Tabela powinna nazywać się `books`.

SQL:

```sql
create table books (
  id bigint generated by default as identity primary key,
  title text not null,
  author text not null,
  genre text not null,
  rating int not null check (rating >= 1 and rating <= 5),
  description text not null,
  created_at timestamptz default now()
);

alter table books enable row level security;

create policy "Allow public read"
on books for select
using (true);

create policy "Allow public insert"
on books for insert
with check (true);

create policy "Allow public delete"
on books for delete
using (true);
```
