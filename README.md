# Moja Biblioteka — projekt semestralny, dzień 1

Autor: Volodymyr Doroshevych  
Indeks: 77442

To jest pierwszy etap prostej aplikacji webowej inspirowanej serwisami książkowymi.

## Co działa w tej wersji

- dodawanie książki przez formularz,
- wyświetlanie listy książek,
- wyświetlanie szczegółów wybranej książki,
- usuwanie książki,
- wyszukiwanie po tytule lub autorze,
- filtrowanie po gatunku,
- licznik książek,
- zapis danych w localStorage przeglądarki.

## Technologie

- HTML — struktura strony,
- CSS — wygląd aplikacji,
- JavaScript — logika aplikacji,
- localStorage — tymczasowe lokalne przechowywanie danych.

## Jak uruchomić lokalnie

Otwórz plik `index.html` w przeglądarce.

Ważne: pliki `index.html`, `style.css` i `app.js` muszą znajdować się w tym samym folderze.
