# Moja Biblioteka

Autor: Volodymyr Doroshevych  
Numer indeksu: 77442

## Opis projektu

Moja Biblioteka to prosta aplikacja webowa umożliwiająca zarządzanie listą książek. Projekt został wykonany jako pierwszy etap aplikacji podobnej do serwisu LubimyCzytać.

Aplikacja pozwala dodawać książki, wyświetlać ich listę, pokazywać szczegóły, edytować dane oraz usuwać wybrane pozycje. Dane są zapisywane w Firebase Realtime Database, dlatego pozostają dostępne po odświeżeniu strony.

## Funkcje

- dodawanie książek;
- wyświetlanie listy książek;
- pokazywanie szczegółów książki;
- edycja danych książki;
- usuwanie książek;
- wyszukiwanie książek;
- zapis danych w Firebase Realtime Database.

## Technologie

- HTML
- CSS
- JavaScript
- Firebase Realtime Database
- GitHub Pages
